# Source Code Plan

Suggested modules:

- `data_prep`: boundary, grid, CRS, geometry repair, raster/vector clipping.
- `features`: morphometric, surface model, vegetation, street-network, and remote-sensing features.
- `models`: baseline ML, deep-learning branches, fusion model, training configs.
- `validation`: spatial CV, ablation, uncertainty, sensitivity tests.
- `visualization`: publication figures, maps, supplementary diagnostics.

Prefer small reproducible scripts over one large notebook.
